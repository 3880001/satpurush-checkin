# Satpurush Check-In App

This is a static HTML + Supabase app.

## Deploying to Netlify (GitHub method)

1. Upload these files to the root of your GitHub repo:
   - index.html
   - netlify.toml
   - README.md

2. Go to https://app.netlify.com/start

3. Choose "Import from GitHub".

4. Select this repository.

5. Build command: (leave empty)

6. Publish directory: .

7. Deploy.

Netlify will NOT inject HUD scripts when deployed from GitHub.
